# Changelog

All notable changes to Lokalweb are documented here.

## 1.2.0 - 2026-08-20

- Added a persistent native menu-bar workflow with dashboard restoration.
- Added isolated nginx and Apache routing with per-site server selection.
- Added per-site PHP 8.3, 8.4 and 8.5 selection.
- Added MariaDB import, export and snapshot workflows.
- Added transactional one-click WordPress installation through WP-CLI.
- Added plugin development-folder linking and WordPress diagnostics.
- Added hardened local release packaging and automated integration coverage.
